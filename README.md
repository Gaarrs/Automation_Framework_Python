Automation Framework Python
Фреймворк UI- и API-автотестов для учебного интернет-магазина [Automation Exercise](https://automationexercise.com/). UI-сценарии используют Playwright и Page Object Model, API-сценарии отправляют запросы через `APIRequestContext`. Pytest запускает тесты, Allure формирует отчёты, а GitHub Actions запускает набор в Docker.
